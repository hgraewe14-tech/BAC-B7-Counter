# Blazing 7s Baccarat Tracker

## About the Project

I built this Excel workbook to help organize and track information while observing Blazing 7s baccarat games. I wanted something that would make it easier to record bets, follow changes throughout a shoe, and review the information afterward without having to calculate everything manually.

The workbook is designed around an 8-deck shoe and includes a few different tools to help keep the information organized.

## Features

- **Hand Log:** Record individual hands, observed wagers, and other relevant details.
- **Table Limits:** Enter the table's minimum and maximum bets.
- **Bet Spread Calculator:** Automatically calculates the spread using the table limits and entered bet amounts.
- **Remaining Cards:** Keep track of exposed cards and estimate the remaining shoe composition.
- **Dashboard:** View important information in one place.
- **Rules and Notes:** Keep useful reference information alongside the tracker.

## How to Use It

1. Open the workbook in Microsoft Excel.
2. Enter the baccarat table's minimum and maximum betting limits.
3. Record the observed wagers and hand information in the Hand Log.
4. Use the spread calculator to compare bet amounts with the table's minimum.
5. Update the card information as cards are exposed throughout the shoe.
6. Review the dashboard and recorded information when needed.
